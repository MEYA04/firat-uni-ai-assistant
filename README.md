🎓 Fırat University AI Assistant v3.0
This project is a high-performance RAG (Retrieval-Augmented Generation) based chatbot designed to assist students and faculty at Fırat University. It specifically focuses on university regulations, academic procedures, and student guidance by processing complex legal and academic documents.

🚀 Key Features
Custom Knowledge Base: Integrated with over 40 official university regulations and documents (PDF/TXT).

Hybrid AI Architecture: Combines Gemini-1.5-Flash for natural language generation and ChromaDB for efficient semantic search.

Intelligent Student Advisor: Capable of answering specific questions about summer school, GPA requirements, transfer policies, and more.

Real-time Interface: Built with Gradio for a seamless and interactive user experience.

🛠 Technical Stack
Language Model: Google Gemini API

Vector Database: ChromaDB (for document embedding and retrieval)

Preprocessing: Custom scripts for cleaning and converting university PDF documents into machine-readable text.

Deployment: Ready for Google Colab and local execution.
